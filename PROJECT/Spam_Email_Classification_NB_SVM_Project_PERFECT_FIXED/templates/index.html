05 · Reproducible methodology

The complete experiment, from raw text to optimized classifier.

The interface is the presentation layer; every displayed metric is produced by the Python ML pipeline and cached as project artifacts.

01

Clean

Retain X = v2 as message input and Y = v1 as the ham/spam target, then remove invalid and duplicate records.

02

Vectorize

TF-IDF with unigram + bigram features turns language into sparse vectors.

03

Compare

Naive Bayes and baseline SVM receive the same train/test split and metrics.

04

Kernel test

Linear, RBF, polynomial and sigmoid kernels are evaluated under shared settings.

05

Tune

Cross-validation explores C, gamma and degree combinations and ranks by F1.

06

Deploy

The optimized SVM and Naive Bayes models power live analysis through Flask.

REPRODUCIBILITY

X = v2 message text · Y = v1 ham/spam target · 80/20 stratified split · random_state = 42 · primary tuning metric: F1-score.
